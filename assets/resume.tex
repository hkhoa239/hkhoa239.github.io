\section*{Research in Progress}

\begin{itemize}
  \item \textbf{MemoryPi.} Explicit long-term memory for vision--language--action policies, so an action can depend on an observation or outcome no longer in the current frame. Motivated by long-horizon failures in RoboMME-style manipulation.
  \item \textbf{Video-to-simulation.} Recover object geometry, hand--object interaction, and demonstrations from monocular human video, then retarget the interaction into a robot simulator.
  \item \textbf{Generative evaluation.} Action-conditioned robot video and learned world models as an evaluation signal where authored 3D assets are insufficient. The open question is when a predicted visual future is reliable enough to judge a policy.
\end{itemize}
